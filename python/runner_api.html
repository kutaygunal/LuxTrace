LuxTrace — Python API & Job Protocol

Drive the tracer from a script: one call, one operation, one JSON reply. Protocol v1 · 13 operations · matches LuxTrace 1.0.0. Deep dive (internals, graphs, workflows): api_guide.html

Contents — Quick start · The luxtrace client · Operations · Config reference · Metrics & budgets · Wire protocol · Error codes · Examples

1 — Quick start

Three places a script can run from. In all three a client object named luxtrace is already in scope — you never start or connect anything.

WhereHow
In the appThe Python tab → edit → Run (or Ctrl+Enter).
Desktop filepython runner.py (no args: a picker opens on your Desktop)
Terminalpython runner.py myscript.py — also --exe, --job job.json, --demo
info = luxtrace.features()
print(info["version"], info["operations"][:4])

res = luxtrace.run({"scene": {"name": "Parabolic Reflector"},
                    "run":   {"rays": 50000, "seed": 42}})
print(res["metrics"]["efficiency"])

Every call returns a plain dict (the envelope's data) or raises LuxTraceError with a machine-readable code and a message.

2 — The luxtrace client

MethodReturnsNotes
features()dictversion, protocol, operation list, scene count
scenes()dictevery scene: name, description, parameters (min/max/step/unit)
materials()dictcatalogue: name, nd, Abbe, description, source
run(config, **params)dictone Monte Carlo trace — the main operation trace
focus(config, **params)dictthrough-focus sweep, best plane, one trace
convergence(config, **params)dictefficiency vs ray count, with a converged verdict
sweep(config, **params)dict1-D parameter sweep on any metric
sweep2d(config, **params)dict2-D sweep as a contour grid
optimise(config, **params)dictNelder-Mead or CMA-ES on any metric
tolerance(config, **params)dictMonte Carlo tolerancing: yield, percentiles, sensitivities
validate(**params)dict13 closed-form checks of the tracer
cad(path, **params)dictimport STEP/IGES, audit it, trace it
rayfile(path, **params)dictdescribe a measured ray set (Zemax binary / text)

The **params are operation options, merged into the call: luxtrace.run(cfg, rays=90000, seed=7, export_csv="out/metrics.csv").

3 — Operations in detail

run — one trace trace

res = luxtrace.run(config, rays=80000, seed=42, threads=0, export_csv="out/metrics.csv")
m = res["metrics"]
Key in dataMeaning
scene, rays, seedwhat was traced (as clamped by the app)
metricsthe full result object — section 5
warningspresent only when a config load recovered from something
exported_csvwith export_csv=path: the metrics table written there

sweep / sweep2d

sw = luxtrace.sweep(config, slot=0, metric="rms_radius_mm",
                    frm=None, to=None,     # defaults: the parameter's own min..max
                    steps=8, repeats=2)
best = min(sw["points"], key=lambda p: p["value"])
OptionMeaning
slot / slot, slot_a, slot_bwhich scene parameter (see luxtrace.scenes() — index and unit there)
metricone of the metric ids
from, to, steps, repeatsthe axis; repeats independent seeds per point

sweep2d returns a[], b[] and values[] (len(a) × len(b), row-major) plus the grid's lo/hi.

optimise

opt = luxtrace.optimise(config, slots=[0, 1], metric="efficiency",
                        goal="maximise",          # or "minimise", or "target" + target=1.0
                        optimiser="neldermead",   # or "cmaes"
                        evaluations=25)
print(opt["start_value"], "->", opt["best_value"])
print({b["name"]: round(b["value"], 1) for b in opt["best_params"]})
print(len(opt["history"]), "evaluations, %.1fs" % opt["seconds"])

tolerance

tol = luxtrace.tolerance(config, metric="efficiency", criterion=0.5,
                         tolerances=[{"slot": 0, "amount": 5.0},
                                     {"slot": 1, "amount": 2.5, "shape": "uniform"}],
                         samples=200)
print("yield %.1f%%" % (100 * tol["yield"]))
for s in tol["sensitivity"]:
    print("  %-16s gradient %+.4f, variance share %.2f" % (s["name"], s["gradient"], s["share"]))

shape is gaussian (default; the limit is 3σ), uniform, or bimodal (worst case). criterion + optional pass_above (default: the metric's own direction) define the pass gate.

focus · convergence · validate

f = luxtrace.focus(config, span_mm=30, steps=61)
print("best focus z = %.1f mm, rms %.2f mm" % (f["best_focus_mm"], f["best_rms_mm"]))

cv = luxtrace.convergence(config, min_rays=1000, max_rays=80000, points=6)
print("converged:", cv["converged"])

v = luxtrace.validate(rays=30000)
print("%d/%d closed-form checks passed" % (v["passed_count"], len(v["cases"])))

cad · rayfile

c = luxtrace.cad("part.step", rays=20000)          # scale=0 reads the file's units
print(c["import"]["format"], c["import"]["total_faces"], "faces")
print("efficiency %.2f %%" % (100 * c["metrics"]["efficiency"]))
# options: scale=1.0, axis=[0,0,1], material="N-BK7", reflective=False, quality=64

r = luxtrace.rayfile("led.dat")                    # measured emitter, then use it:
cfg["source"] = {"rayFile": "led.dat"}
print(r["summary"])

4 — Config reference

A config is the same document the desktop app saves. Missing keys keep their defaults; numbers arrive clamped — a two-line config is valid.

config = {
  "scene":  {"name": "Elliptical Reflector",     # exact names: luxtrace.scenes()
             "params": [200, 120, 160],          # in the order scenes() lists them
             "useDefaults": false},              # true: ignore params, use defaults
  "source": {
      "type": "collimated",                      # point | lambertian | collimated
      "shape": "disc",                           # point | disc | rect | sphere
      "spectrum": "blackbody",                   # monochrome | rgb | blackbody | led | d65 | table
      "wavelengthNm": 550, "cct": 5000,          # per spectrum kind
      "power": 1.0, "powerUnit": "watt",         # watt | lumen
      "halfAngleDeg": 180, "beamRadius": 25,
      "polarisation": "unpolarised",             # unpolarised | linear-s | linear-p | circular
      "rayFile": "led.dat"},                     # overrides type/shape entirely when set
  "run":    {"rays": 100000, "threads": 0, "seed": 12345,   # 0 threads = every core
             "detectorBins": 0, "nTheta": 90, "nPhi": 72},
}

Extras also accepted: extraSources[] (same shape as source), surfaceOverrides[] (ray-time optical edits) and physics (scene-wide overrides). Save a setup in the UI (File → Save configuration) and feed it in unchanged.

6 — The wire protocol (for hosts that skip Python)

LuxTrace.exe --serve: one operation JSON object per stdin line, one envelope per stdout line, until EOF. --job file.json runs a batch document {"ops":[...]}. stdout is JSON and nothing else — every human word goes to stderr.

{"v":1,"seq":0,"id":7,"type":"result","op":"run","data":{...},"ms":1823.4}
{"v":1,"seq":1,"id":8,"type":"error","op":"cad",
 "error":{"code":"import_failed","message":"cannot open nope.step"}}
  • type: result · error (this op failed, the stream continues) · fatal (stream ends, non-zero exit).
  • id echoes whatever the request carried — that is how the client matches replies to calls while operations with long traces are still pending.
  • An operation object: {"op": "...", "id": 7, "params": {...}}.

8 — Two worked examples

Design loop — sweep, pick the best, confirm it converged:

cfg = {"scene": {"name": "Parabolic Reflector"}, "run": {"rays": 40000, "seed": 9}}
sw  = luxtrace.sweep(cfg, slot=0, metric="rms_radius_mm", steps=10)
z   = min(sw["points"], key=lambda p: p["value"])
cfg["scene"]["params"] = [z["parameter"], None, None]         # adopt the winner (others: defaults)
opt = luxtrace.optimise(cfg, slots=[0, 1], metric="rms_radius_mm",
                        goal="minimise", evaluations=30)
cv  = luxtrace.convergence(cfg, min_rays=2000, max_rays=160000, points=5)
print("done:", opt["best_value"], "mm, converged:", cv["converged"])

Determinism. The same config + seed reproduces a result to the last digit — sweep wiggles are noise, optimiser history is a real convergence record, and a yield figure can be checked rather than quoted.
